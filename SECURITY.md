# Security Policy

## Supported versions

Fixes go into `master` and ship in the next release. Only the latest release
is supported.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub](https://github.com/folbricht/routedns/security/advisories/new), or
by email to frank.olbricht@gmail.com.

Include the RouteDNS version, the relevant part of the configuration, and
steps or a query that reproduce the problem.
